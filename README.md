# Contemporary Art Atlas

A standalone GitHub Pages research directory featuring twelve contemporary artists across media.

## Publish
Go to **Settings → Pages → Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then **Save**.

Website URL once enabled: https://ndangelo.github.io/contemporary-art-atlas/

## Files
- `index.html` — responsive dark interface
- `app.js` — artist profiles, search, filters and APA-style reference copying
- `.nojekyll` — GitHub Pages static site configuration

## Editorial status
This is a starter research archive, not yet publication-ready academic scholarship. Source metadata and artist summaries require verification. Artwork is linked from external institutions and artists rather than reproduced without permissions.
